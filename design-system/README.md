# Growth Score design system

Tokens for the Growth Score brand, published by Closing Foundry Ltd.

- `tokens.css` — the single source of truth. Colour, type scale, leading, shape, space.
- Live reference: https://score.closingfoundry.com

## Rules that matter more than the values

1. **Thirteen font sizes, no others.** No half pixels.
2. **Three leading ratios, no others.** 1.1 display, 1.4 interface, 1.6 reading.
3. **One accent.** `#0B4ED6`. If something needs to stand out and blue is taken, use weight or space.
4. **No shadows.** Cards do not float. The focus ring is the only exception.
5. **3px radius everywhere.** Near square.
6. **No icons, no photography.** Every graphic is data, drawn as inline SVG.
7. **Amber is reserved.** It means one thing: this figure is not verified.
8. **No gradients, no glassmorphism, no serif.**

## Voice

UK English. No em dashes or en dashes. Never claim the measure predicts growth,
improves funding odds, or causes improvement. State what is not claimed as
prominently as what is.
