Version history

Every change, and whether it broke comparability.

A longitudinal measure is worthless if the method quietly changes underneath it. Each entry states plainly whether scores either side of the change can still be compared. That single field is what a report covering two dates depends on.

When a peer benchmark gets published

Not until there’s a defensible cohort: provisionally at least 100 comparable observations per segment, with the exact threshold set against the observed distribution on statistical advice. At 31 companies measured in total, no segment is close, so no percentile is shown anywhere in the product. We could display one today and it would be fiction.
